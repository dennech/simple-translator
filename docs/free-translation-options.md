# Бесплатный перевод: варианты и ограничения

Проверено **17 ноября 2026 года** по официальной документации, страницам тарифов и репозиториям авторов. Это широкий обзор практических вариантов, а не обещание охватить каждый сервис. Регистрации, реальные API-запросы и сравнительные испытания качества не выполнялись. Условия могут измениться; наличие бесплатного тарифа на сайте не гарантирует доступ конкретному аккаунту.

**В настройках доступны все 20 облачных сервисов из этого обзора.** У 16 новых подключений проверены протоколы и тестовые ответы, но реальные запросы с пользовательскими ключами ещё не проверены. Локальные Apple Translation, Argos/LibreTranslate, Ollama/LM Studio, Apertium и Bergamot остаются справочником и пока не встроены. [Как подключить сервис](connections.md), [технические контракты](provider-api-contracts.md).

Бесплатная квота возобновляется; пробный кредит заканчивается. Бесплатный сайт переводчика и API для других приложений — разные продукты. Например, DeepL отдельно описывает планы API и подписки на свои приложения; Google Cloud Translation требует отдельного проекта и расчётного аккаунта. [DeepL](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans), [Google Cloud](https://docs.cloud.google.com/translate/docs/setup).

## Быстрый выбор

| Задача | Варианты | Главное ограничение |
| --- | --- | --- |
| Попробовать в этом приложении | OpenRouter `:free`, бесплатный уровень Gemini | Ограничения запросов, доступность моделей и страны; правила обработки текста |
| Попробовать специализированный перевод в приложении | DeepL API Developer | 1 млн знаков всего; старый ежемесячный API Free закрыт для нового оформления |
| Получать регулярную квоту специализированного API | Azure Translator F0; Google Cloud Translation NMT | 2 млн / 500 тыс. знаков в месяц; нужна облачная учётная запись; доступны в настройках |
| Обойтись без расчётного аккаунта для коротких фраз | MyMemory | 5 тыс. знаков в сутки анонимно; долгое хранение текста; доступен в настройках |
| Использовать другие облачные языковые модели | Groq; Cloudflare Workers AI | Бесплатные пределы и ограничения моделей; доступны в настройках |
| Переводить без отправки текста в облако | Apple Translation; Argos/LibreTranslate; локальные модели | Нужны совместимое устройство, модели и отдельная реализация; доступны в настройках |

Подробности и источники приведены ниже. Слово «подходит» означает возможность использовать для такой задачи, а не измеренное превосходство в качестве. Для русского и английского специализированные переводчики указывают языки явно; у универсальных моделей качество зависит от выбранной модели и проверяется на своих примерах. Ни рейтинга качества, ни обещания безошибочного перевода здесь нет.

## Уже поддерживаемые сервисы

### 1. OpenRouter — возобновляемая бесплатная квота

- **Бесплатно:** модели с окончанием `:free`; 20 запросов в минуту и 50 в сутки. После покупки кредитов на $10 суточный предел повышается до 1000 — такой вариант уже предполагает расход денег. Неудачные попытки тоже учитываются. `openrouter/free` выбирает подходящую бесплатную модель, поэтому результат может отличаться от запроса к запросу. [Бесплатные модели](https://openrouter.ai/collections/free-models), [лимиты](https://openrouter.ai/docs/api_reference/limits).
- **Доступ:** аккаунт и API-ключ; для `:free` покупка кредитов не обязательна. Каталог меняется. Для русского ↔ английского выбирайте мультиязычную модель и оценивайте перевод на примерах; популярность в каталоге не является оценкой качества. [Каталог](https://openrouter.ai/collections/free-models).
- **Текст:** проходит через OpenRouter и поставщика вычислений. Запрет обучения и отсутствие хранения — разные условия. Политики поставщиков различаются; ограничения конфиденциальности могут исключить часть бесплатных маршрутов. [Политики поставщиков](https://openrouter.ai/docs/guides/privacy/provider-logging).
- **В приложении:** поддерживается. Выбирайте модель с явно нулевыми входной, выходной и дополнительной ценами. Не путайте `openrouter/free` с платной автоматической маршрутизацией.

### 2. Gemini API — бесплатный уровень отдельных моделей

- **Бесплатно:** вход и выход только у моделей, для которых в столбце Free Tier указана бесплатность. При проверке такой уровень есть у `gemini-3.8-flash`; это не означает бесплатность всех Gemini. На платном уровне действует свой тариф. [Тарифы](https://ai.google.dev/gemini-api/docs/pricing).
- **Лимит:** зависит от модели, проекта и уровня аккаунта; смотрите текущие пределы в AI Studio. Не обещаем универсальные «1500 запросов в сутки» или другую старую цифру. Начать можно с бесплатного уровня без включения платного использования. [Лимиты](https://ai.google.dev/gemini-api/docs/rate-limits), [оплата](https://ai.google.dev/gemini-api/docs/billing).
- **География:** России нет в опубликованном списке доступных стран Gemini API/AI Studio. Наличие языка «русский» не означает доступ сервиса из России. [Доступные страны](https://ai.google.dev/gemini-api/docs/available-regions).
- **Текст:** на бесплатном уровне Google может использовать запросы и ответы для улучшения продуктов; учитывайте условия своего региона. Для конфиденциальной переписки сначала изучите правила. [Тарифы](https://ai.google.dev/gemini-api/docs/pricing), [условия](https://ai.google.dev/gemini-api/terms).
- **В приложении:** поддерживается; русско-английский перевод выполняется как задача универсальной модели, без отдельной гарантии качества.

### 3. DeepL API — пробный Developer и прежний API Free

- **Для нового аккаунта:** API Developer даёт **1 000 000 знаков за всё время**, без возобновления. Это пробный объём, а не миллион каждый месяц. Регистрация рекламируется без банковской карты. [Планы](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans), [начало работы](https://www.deepl.com/en/developers).
- **Для прежнего API Free:** 500 000 знаков в месяц, но оформить этот план заново уже нельзя. Подписка на приложение DeepL не заменяет план API. [Планы API](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans).
- **Доступ и текст:** нужен аккаунт и отдельный API-ключ. Не переносите обещания конфиденциальности платных подписок автоматически на Developer/Free: изучите условия своего плана. Список доступных платных планов не включает Россию; доступ бесплатного Developer в конкретной стране отдельно не подтверждён. [Защита данных](https://support.deepl.com/hc/en-us/articles/26380849099932-DeepL-infrastructure-and-data-protection), [страны](https://support.deepl.com/hc/en-us/articles/360020016339-Countries-and-regions-where-DeepL-paid-plans-are-available).
- **В приложении:** поддерживается; для русского и английского используйте доступные вашему плану языки. [Языки API](https://developers.deepl.com/docs/getting-started/supported-languages).

### OpenAI API — платный тариф и отдельные бонусы подписчикам

**Уже подключён.** Общедоступная постоянная бесплатная квота для перевода через API не заявлена; стоимость определяется моделью и использованием. Нужны отдельный API-ключ и доступный баланс. ChatGPT и API имеют раздельный учёт — само наличие подписки не подтверждает оплату запросов приложения. [Тарифы API](https://developers.openai.com/api/docs/pricing), [раздельный учёт](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).

При этом категоричное «ChatGPT никогда не даёт API-кредитов» тоже неверно: подходящие платные **Pro и Business** могут активировать бонусные API-кредиты; **Plus** не подходит. Нужна отдельная активация, предложение зависит от аккаунта и страны, остаток ограничен сроком. Это льгота платной подписки, а не бесплатный старт для всех. Сначала проверьте фактически выданный кредит в нужной API-организации. [Условия бонуса](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions).

Для RU/EN перевод выполняется выбранной языковой моделью; сравнительного испытания здесь нет. По умолчанию данные API не используются для обучения без согласия, но возможны журналы безопасности и хранение, зависящее от функции; выключенное сохранение ответа не является универсальной гарантией отсутствия журналов. [Управление данными](https://developers.openai.com/api/docs/guides/your-data). Страну доступа проверяйте по [официальному списку](https://developers.openai.com/api/docs/supported-countries).

## Другие регулярные бесплатные квоты

Все пять сервисов этого раздела доступны в настройках; требуется проверка вашим аккаунтом. Если страна прямо не указана, доступность регистрации и использования в ней в рамках этого исследования не подтверждена.

### 4. Azure Translator F0

**2 млн знаков в месяц** для стандартного перевода и обучения пользовательского перевода в общей бесплатной квоте F0. Это не бесплатный доступ ко всем услугам Azure. Нужны аккаунт Azure, ресурс Translator и ключ; обычная регистрация Azure требует телефон и банковскую карту, возможна временная проверочная блокировка небольшой суммы. [Тариф Translator](https://azure.microsoft.com/en-us/pricing/details/translator/), [регистрация](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account).

Русский и английский поддерживаются. Для текстового перевода действует политика без сохранения исходного текста; документы временно обрабатываются отдельно. Это практичный кандидат на дальнейшее подключение при подходящей стране регистрации. [Языки](https://learn.microsoft.com/azure/ai-services/translator/language-support), [обработка данных](https://learn.microsoft.com/en-us/azure/foundry/responsible-ai/translator/data-privacy-security).

### 5. Google Cloud Translation NMT

**500 000 знаков в месяц**, оформленные как ежемесячный кредит до $10, общий для Basic и Advanced. Не переносится на следующий месяц. Речь о стандартном нейронном переводе NMT; это не бесплатная квота Translation LLM или форматированных документов. Превышение оплачивается. [Тарифы](https://cloud.google.com/products/translate/pricing).

Нужны Google Cloud проект, включённый API и активная оплата; конкретный доступный способ оплаты зависит от расчётного аккаунта. Русский и английский есть в списке. Google заявляет, что не использует тексты этого API для обучения, держит их кратковременно в памяти для обработки. Эти правила отличаются от бесплатного Gemini. [Настройка](https://docs.cloud.google.com/translate/docs/setup), [языки](https://docs.cloud.google.com/translate/docs/languages), [данные](https://docs.cloud.google.com/translate/data-usage).

### 6. MyMemory

**5000 знаков в сутки** анонимно; **50 000** при передаче действительного адреса электронной почты. Аккаунт и карта для анонимного режима не нужны. Один сегмент ограничен **500 байтами**, что особенно важно для кириллицы; это не 500 русских букв. API объединяет поиск готовых переводов и машинный перевод; для RU/EN подходит прежде всего как вариант коротких фраз с проверкой результата. [Квоты](https://mymemory.translated.net/doc/usagelimits.php), [API](https://mymemory.translated.net/doc/spec.php).

**Не для закрытых текстов:** условия предусматривают долговременное хранение переданных сегментов и участие внешних поставщиков. Публикация в общей памяти и обычный запрос — разные операции, но считать обычный запрос приватным без хранения нельзя. Условия запрещают перевод больше одного абзаца за раз и обход лимитов. [Условия MyMemory](https://mymemory.translated.net/terms-and-conditions).

### 7. Groq

Бесплатный уровень API существует; платёжный метод требуется при переходе на Developer. Квоты различаются по моделям и организации: запросы и токены за минуту/сутки. В текущей таблице для `qwen/qwen3.8-27b` указаны 30 запросов/мин, 1000/сутки, 8000 токенов/мин и 200 000/сутки, но точное действующее значение нужно смотреть в аккаунте. Нужны аккаунт и ключ. [Оплата](https://console.groq.com/docs/billing-faqs), [лимиты](https://console.groq.com/docs/rate-limits).

Для RU/EN можно пробовать мультиязычную модель из текущего каталога; скорость сервиса сама по себе не гарантирует качество перевода. По умолчанию содержание обычных запросов не сохраняется; возможны исключения для отладки и борьбы со злоупотреблениями, а также функций, требующих хранения. [Обработка данных](https://console.groq.com/docs/your-data).

### 8. Cloudflare Workers AI

**10 000 Neurons в сутки** на бесплатном плане — внутренние единицы вычислений, а не 10 000 запросов или знаков. Расход зависит от модели. Дневной сброс в 00:00 UTC; превышение на Free приводит к ошибке. Часть моделей требует платного способа использования, поэтому наличие модели в общем каталоге не означает её доступность на Free. Нужен аккаунт Cloudflare и API-токен; карта для конкретной регистрации отдельно не проверялась. [Тарифы](https://developers.cloudflare.com/workers-ai/platform/pricing/).

Для RU/EN требуется подходящая мультиязычная модель и проверка результата. Для обычных запросов заявлены отсутствие обучения на содержимом и отсутствие его дальнейшего хранения после обработки с оговорёнными исключениями; включённые журналы, кеши и другие сервисы могут сохранять данные. [Данные](https://developers.cloudflare.com/workers-ai/platform/data-usage/).

## Пробный доступ и предложения, которые нельзя обещать как постоянную квоту

Для всех вариантов этого раздела добавлены подключения; реальный доступ зависит от вашего аккаунта. У универсальных моделей пригодность для русского ↔ английского зависит от модели. Если ниже не подтверждены карта, страна или конкретная политика хранения, это означает «не установлено», а не «ограничений нет».

### 9. Cerebras

Актуальная страница тарифов предлагает **одноразовые $5 на 30 дней после добавления действующего способа оплаты**. Доступ останавливается при исчерпании/истечении кредита, если отдельно не куплены PayGo-кредиты. Это заменяет обещание постоянного бесплатного миллиона токенов из старых обзоров; старая страница документации ещё может описывать Free. Нужен аккаунт. В каталоге есть мультиязычные модели, но качество RU/EN здесь не измерялось. [Действующие тарифы](https://www.cerebras.ai/pricing).

Это облачная обработка; правила конфиденциальности и возможные исключения проверяются по актуальной политике, а не по слову «бесплатно». [Политики Cerebras](https://www.cerebras.ai/policies).

### 10. Fireworks AI

Официальные материалы описывают **$1 стартового кредита**, а действующая страница тарифов — предоплату и покупку кредитов. Поэтому стартовый бонус следует считать **условным разовым предложением, которое надо увидеть в своём аккаунте**, а не гарантированной новой квотой. Старый FAQ допускает работу до исчерпания $1 без платёжного метода; дальнейшее использование оплачивается. [FAQ о кредите](https://fireworks.ai/docs/faq-new/billing-pricing/what-happens-when-i-finish-my-1-dollar-credit), [актуальные тарифы](https://fireworks.ai/pricing).

Нужны аккаунт и ключ. Облако предлагает различные текстовые модели; RU/EN проверяется на выбранной модели. География и применимые условия хранения в этом обзоре отдельно не установлены; нельзя считать сервис локальным или автоматически конфиденциальным. [API текстовых моделей](https://docs.fireworks.ai/guides/querying-text-models), [условия](https://fireworks.ai/terms-of-service).

### 11. NVIDIA API Catalog / NIM

Доступ для **проверки и разработки**, а не обещание бесплатного рабочего сервиса. Точные актуальные квоты/кредиты зависят от предложения и аккаунта; старые цифры «1000/5000 навсегда» не подтверждены. Нужна регистрация; обязательность карты для конкретного варианта не установлена. [Условия пробного API, раздел 1](https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf).

Для RU/EN нужен подходящий языковой движок. Условия ограничивают использование пробного API и его результатов в рабочей эксплуатации; к содержимому применяются отдельные положения об использовании и обработке данных. Поэтому этот вариант уместен для синтетических проверок, а не как основной бесплатный переводчик личной переписки. [Условия API](https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf).

### 12. Amazon Translate

Страница продукта указывает **2 млн знаков в месяц до 12 месяцев с первого запроса**. Это ограниченная по времени льгота. При этом общая программа AWS Free Tier менялась: для нового аккаунта необходимо проверить применимые предложение, срок и кредиты в расчётном разделе; не считать старую продуктовую цифру безусловной гарантией для любой новой регистрации. Нужен AWS-аккаунт; условия проверки карты зависят от выбранного оформления. [Тариф Translate](https://aws.amazon.com/translate/pricing/), [AWS Free Tier](https://aws.amazon.com/free/).

Это специализированный переводчик; языки и регионы проверяются в документации. Amazon Translate может хранить данные для улучшения моделей; предусмотрен отказ от такого использования. [Языки](https://docs.aws.amazon.com/translate/latest/dg/what-is-languages.html), [данные и ограничения](https://docs.aws.amazon.com/translate/latest/dg/what-is-limits.html), [отказ от улучшения сервисов](https://docs.aws.amazon.com/accounts/latest/reference/opt-out-ai-data-use.html).

## Популярные названия, у которых бесплатный API сейчас не подтверждён

Они включены, чтобы не принять старую рекомендацию или бесплатный веб-чат за действующую бесплатную интеграцию. Для всех добавлены подключения; отправка текста в их API остаётся облачной обработкой. Отдельная проверка конфиденциальности и доступности страны нужна перед использованием.

### 13. Mistral Free / прежний Experiment

[Текущая документация](https://docs.mistral.ai/admin/billing-usage/usage-limits), [противоречащая справка](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-do-i-increase-them).

Для Free Studio данные могут использоваться для обучения с возможностью отказа; это отдельный вопрос от наличия API. Русско-английский перевод зависит от модели. Локальные открытые модели Mistral остаются отдельным вариантом. [Правила данных](https://help.mistral.ai/en/articles/347617-do-you-use-my-user-data-to-train-your-artificial-intelligence-models), [официальные варианты запуска](https://help.mistral.ai/en/articles/347391-how-can-i-quickly-test-your-ai-models).

### 14. Hugging Face Inference Providers

Бесплатное скачивание открытых моделей и бесплатные демонстрации Spaces не равны бесплатному универсальному API. [Тарифы Inference Providers](https://huggingface.co/docs/inference-providers/pricing).

Нужны аккаунт и токен, а для облачного выполнения — оплаченный доступ. Модель и поставщик определяют пригодность для RU/EN и обработку текста; Hugging Face может выступать маршрутизатором. Конкретные гарантии приватности здесь не установлены. [Маршрутизация](https://huggingface.co/docs/inference-providers/hub-integration), [безопасность](https://huggingface.co/docs/inference-providers/security).

### 15. Together AI

Документация прямо сообщает: **бесплатных проб сейчас нет**, для начала нужна покупка минимум **$15**; до неё недоступны даже создание API-ключей и Playground. Это платный вариант, независимо от старых сообщений о стартовых бонусах. Нужен аккаунт и поддерживаемый способ оплаты. [Кредиты и условия доступа](https://docs.together.ai/docs/billing-credits).

Для RU/EN подходят только соответствующие модели; в исследовании они не сравнивались. Условия хранения нужно сверять для своего режима и функций. [Конфиденциальность](https://docs.together.ai/docs/privacy-and-security).

### 16. SambaNova Cloud

Поэтому название Free нельзя трактовать как подтверждённую бесплатную квоту. Старые сообщения о ежесуточном доступе или $5 при регистрации здесь не принимаются как актуальная гарантия. Нужен аккаунт. [Действующие планы](https://cloud.sambanova.ai/plans).

## Локально, без оплаты каждого перевода

Эти варианты **пока не встроены**. После подготовки моделей перевод может выполняться на устройстве. Здесь «бесплатно» означает отсутствие платы поставщику за каждый запрос; остаются требования к памяти, месту, мощности, электричеству и лицензии. Ниже нет обещания, что любая модель заработает на любом Mac.

### 18. Apple Translation framework

Нативный системный механизм: `TranslationSession` использует модели на устройстве и общие языковые пакеты. Пакеты могут потребовать первоначальной загрузки. Для использования перевода не нужен сторонний API-ключ или карта; отдельная облачная квота на запросы не заявлена. API доступен в современных версиях macOS; совместимость конкретного устройства и языковой пары проверяется системным API. [Обзор Apple](https://developer.apple.com/videos/play/wwdc2024/10117/), [TranslationSession](https://developer.apple.com/documentation/Translation/TranslationSession).

Русский и английский перечислены для системного перевода macOS, но готовность загруженных языков всё равно проверяется на устройстве. Это естественный кандидат для нативного приложения без внешнего сервера. [Языки macOS](https://www.apple.com/macos/feature-availability/). Нативность не заменяет проверку точности перевода.

### 19. Argos Translate / свой LibreTranslate

**Argos** — открытый локальный переводчик с языковыми пакетами; русский и английский входят в поддерживаемые языки. **LibreTranslate** — серверный интерфейс поверх этой технологии, который можно поднять у себя и использовать без внешней квоты. Для собственного запуска не нужны внешний аккаунт и карта, текст можно оставить на своём устройстве. [Argos](https://github.com/argosopentech/argos-translate), [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate).

Это не обещание бесплатного безлимитного доступа к чужому серверу `libretranslate.com`: бесплатен код и собственный запуск. Требуются установка среды и моделей; их качество и направление RU→EN/EN→RU нужно проверять отдельно. При распространении учитывайте лицензии Argos и LibreTranslate, а также пакетов моделей. [Официальные репозитории и лицензии](https://github.com/LibreTranslate/LibreTranslate).

### 20. Ollama / LM Studio и открытые модели

Можно скачать модель и выполнять перевод локально через Ollama или LM Studio; у локальных запросов нет облачной платы за токены. LM Studio отдельно подтверждает работу локального сервера без интернета и бесплатное использование на работе. Не путайте локальную модель с облачным режимом того же приложения. [Ollama Local FAQ](https://docs.ollama.com/faq), [LM Studio офлайн](https://lmstudio.ai/docs/app/offline), [LM Studio на работе](https://lmstudio.ai/blog).

Кандидаты для проверки RU/EN: мультиязычные Qwen и специализированная TranslateGemma. Размер, формат и поддержка в конкретной программе проверяются перед загрузкой; название семейства не гарантирует одинаковое качество всех размеров. Qwen3-8B опубликована под Apache 2.0; TranslateGemma требует соблюдения лицензии Gemma. Иногда для скачивания нужен аккаунт и принятие условий модели, но не оплата переводов. [Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B), [TranslateGemma](https://huggingface.co/google/translategemma-4b-it).

### 21. Apertium

Открытая система перевода на лингвистических правилах, возможен локальный запуск без облачного аккаунта и квоты; текст остаётся на устройстве при таком запуске. Но русско-английская пара отмечена **incubator**, то есть незавершённая. Поэтому для основного RU↔EN это исследовательский вариант, а не рекомендуемая готовая замена. Для других, особенно близких языков, статус пары может быть лучше. [Пара EN–RU](https://wiki.apertium.org/wiki/Apertium-en-ru), [статусы языковых пар](https://wiki.apertium.org/wiki/List_of_language_pairs).

### 22. Bergamot / Firefox Translations

Открытый движок локального нейронного перевода: содержание не отправляется в облако. Самостоятельный движок можно исследовать отдельно; бесплатный перевод в Firefox уже является готовым пользовательским вариантом без API-ключа. Это **не облачный API для нашего приложения** и не повод добавлять браузерную оболочку. [Проект Bergamot](https://browser.mt/), [перевод в Firefox](https://support.mozilla.org/en-US/kb/website-translation).

Набор языков и направления меняются; старый список Bergamot и текущие пакеты Firefox могут отличаться. Для RU↔EN нужно проверить актуальную пару и конкретную сборку, не обещая поддержку по одному названию движка. Для нативного встраивания понадобятся отдельные работы с библиотекой и моделями. [Актуальная справка Firefox](https://support.mozilla.org/en-US/kb/website-translation).

## Что проверять перед выбором

1. Нужен ли именно API для приложения или достаточно самостоятельного сайта/локальной программы.
2. Возобновляется ли бесплатный объём, когда он сбрасывается и что происходит после исчерпания.
3. Есть ли выбранная модель в бесплатном уровне именно вашего аккаунта; не включилась ли платная оплата.
4. Можно ли передавать такой текст выбранному поставщику: отсутствие обучения не означает отсутствие журналов или временного хранения.
5. Доступны ли регистрация, нужная страна и способ оплаты; отсутствие сведений в обзоре не означает отсутствие ограничений.
6. Сохраняются ли имена, числа, отрицания, абзацы и смысл на нескольких своих несекретных примерах в обоих направлениях.

Официальные лимиты и тарифы имеют приоритет над этой справкой. В обзор не включены неофициальные запросы к веб-интерфейсам, скрейпинг переводчиков и способы обхода квот.
