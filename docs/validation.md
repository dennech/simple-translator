# Проверки приложения

Проверено на macOS с Apple Silicon. Приложение собрано в режиме Release для arm64 и x86_64, подпись проверена командой `codesign --verify --strict`. Включены App Sandbox и разрешение исходящих сетевых соединений. Запуск на физическом Intel Mac не проверялся.

## Автоматические проверки

`swift test`: 14 проверок. Проверяются:

- разделение длинного Unicode-текста без потери символов, границы частей и переносы строк;
- автоматическое направление перевода и определение русского/английского;
- потоковый ответ, прерывание, обрезка и отказ модели;
- отмена отложенного запроса;
- разделение системной инструкции и переводимого текста в запросе;
- параметры OpenAI и отключение сохранения ответа;
- маркировка бесплатных моделей, фиксированная плата за запрос и неизвестные тарифы.
- сохранение предыдущего перевода при редактировании и ошибке, перевод только нового абзаца;
- защита от запоздавшего ответа отменённого запроса;
- отсутствие ключа, удалённого текста ошибки и адреса запроса в сообщениях об ошибках;
- одно чтение ключа за сеанс, замена и удаление его копии из памяти, повтор после отказа в доступе.

Проверки формы запроса не доказывают, что языковая модель всегда игнорирует команды внутри переводимого текста.

## Проверка интерфейса

Проверены запуск собранного приложения, перевод с английского, обратное направление, сохранение абзацев, оформление и отдельные настройки. Проверены список моделей, цены и фильтр «Только бесплатные», справочник из 25 карточек и поиск по нему. При добавлении нового абзаца готовый перевод первого абзаца сохранился.

Вставлен синтетический текст из 65 пронумерованных пунктов, 9349 знаков. Готовый перевод содержал все 65 пунктов в правильном порядке. После проверки пример очищен. Личные пользовательские тексты не использовались.

Проверен реальный перевод через OpenAI, OpenRouter и DeepL. Каталог Gemini загружался; доступ к переводу зависит от условий конкретного аккаунта.

## Сборка для скачивания

ZIP содержит только приложение и общедоступный справочник. Проверяются обе архитектуры, подпись после распаковки, отсутствие личных путей и ключей в исполняемом файле, состав архива и SHA-256. У сборки нет Developer ID и нотариального заверения Apple: при первом скачивании возможно системное подтверждение запуска. Локальная подпись также может вызвать повторное подтверждение Связки ключей после обновления; разрешённый ключ затем используется из памяти в пределах сеанса.

## Ограничения

Единичный успешный запрос не гарантирует доступности сервиса, качества всех языковых пар или постоянной скорости. Бесплатные модели ограничены квотами. Для будущих моделей нужно проверять совместимость API.

Перед публикацией проверяются файлы и авторы коммитов. В репозитории нет ключей, пользовательских текстов, локальных путей, отчётов о личных аккаунтах или персональных контактных данных.
