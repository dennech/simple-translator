# Как подключить сервис перевода

Откройте настройки кнопкой ⚙︎ или **⌘,**, выберите сервис и добавьте собственные данные доступа. Приложение не выдаёт общие ключи и не подключает оплату за пользователя. Новые интеграции проверены на тестовых ответах; доступ реального аккаунта, тариф и качество нужно проверить своим ключом.

## Обычный API-ключ

Для OpenAI, OpenRouter, Gemini, DeepL, Groq, Cerebras, Fireworks, NVIDIA NIM, Mistral, Together, SambaNova и SiliconFlow достаточно ключа выбранного сервиса. Ссылка **«Получить ключ»** открывает официальный кабинет или инструкцию.

1. Вставьте ключ в защищённое поле и нажмите **«Сохранить»**.
2. Нажмите **«Выбрать из списка…»** и выберите текстовую модель. Если каталог недоступен, её точный ID можно ввести вручную.
3. Нажмите **«Проверить перевод»**. Это реальный небольшой запрос; он расходует квоту или оплачивается по тарифу.

Для новых языковых сервисов модель изначально не выбрана. Самостоятельной замены модели при ошибке или исчерпании квоты нет. У DeepL список режимов встроен в приложение, остальные каталоги загружаются из API. SiliconFlow использует международный сервис `.com`; ключ китайской платформы `.cn` сюда не подходит.

## Подключения с особенностями

| Сервис | Что понадобится | Что выбрать или заполнить |
| --- | --- | --- |
| **Azure Translator** | Ключ ресурса Translator | Регион нужен у регионального или общего ресурса; у global Translator можно оставить пустым. Модель — «Стандартный перевод». |
| **Google Cloud Translation** | API-ключ проекта с включённым Translation API и оплатой | Используется Basic v2 с моделью NMT. Project ID отдельно вводить не требуется. Ключ передаётся в заголовке, а не в адресе запроса. |
| **MyMemory** | Ничего для анонимного режима | Можно сразу переводить. Email необязателен; он сохраняется в Связке ключей и передаётся сервису для увеличения квоты. Для закрытой переписки этот вариант не рекомендуется. |
| **Cloudflare Workers AI** | API-токен с правом Workers AI: Read | Account ID из панели Cloudflare, затем «Применить параметры» и выбор текстовой модели. Не вставляйте Global API Key вместо токена. |
| **Hugging Face** | Токен с правом Inference Providers | Каталог показывает пары `модель:поставщик`. Выберите конкретную пару. Варианты `:auto`, `:fastest`, `:cheapest`, `:preferred` не используются. |
| **Amazon Translate** | Access Key ID + Secret Access Key | Для временных данных добавьте Session Token. Все три значения сохраняются одной защищённой записью. Выберите регион и примените параметры. Нужны права `translate:TranslateText`. |
| **Yandex Translate** | API-ключ сервисного аккаунта с правами перевода | Используется режим `Api-Key`. IAM-токены в этом подключении не принимаются; folderId не нужен. |
| **GigaChat** | Готовый Authorization Key из кабинета | Выберите тип аккаунта: личный, бизнес или корпоративный. Приложение само получает временный токен и держит его только в памяти. Не кодируйте готовый ключ повторно. |

Точные методы и ссылки официальных инструкций собраны в [техническом справочнике API](provider-api-contracts.md). Наличие подключения в приложении не означает бесплатность: условия показаны в справочнике в настройках и в [обзоре тарифов](free-translation-options.md).

### GigaChat и сертификаты

Для авторизации GigaChat macOS должна доверять цепочке сертификатов сервиса. При ошибке защищённого соединения используйте [официальную инструкцию GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates). Приложение не устанавливает корневые сертификаты, не отключает проверку TLS и не принимает неизвестные сертификаты автоматически.

### Связка ключей macOS

Простой просмотр настроек проверяет только метаданные записи и не читает секрет. Ключ потребуется при переводе, явной проверке подключения или загрузке закрытого каталога моделей. После разрешённого чтения он используется из памяти до завершения приложения. Обновление локально подписанной сборки может снова потребовать разрешения macOS.

Ключи не показываются в форме при повторном открытии настроек. Для замены ключа AWS нужно заново ввести Access Key ID и Secret Access Key, а для временной пары — также Session Token. Если временные учётные данные истекли, сохраните новую пару.

### Ограничения первой версии подключений

- Проверки на тестовых HTTP-ответах не подтверждают доступ к сервису из вашей страны или наличие бесплатной квоты.
- Каталоги меняются; у Fireworks первоначально показываются доступные модели из публичного аккаунта. Собственный ID развёрнутой модели можно ввести вручную.
- SambaNova пока получает обычный JSON-ответ: перевод появляется по завершении части текста. Остальные языковые API используют поток там, где это предусмотрено контрактом.
- Облачные сервисы не поддерживают все языковые пары одинаково. Для Amazon и MyMemory автоопределение выполняется локально; если язык не определился, выберите его вручную.
- Локальные Apple Translation, Argos/LibreTranslate, Ollama/LM Studio, Apertium и Bergamot перечислены в справочнике, но пока не встроены.
